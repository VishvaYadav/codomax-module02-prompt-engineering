## 🧠 What I built

**1. Prompting fundamentals:** compared zero-shot and few-shot sentiment classification, a vague prompt against a structured
*Role → Context → Instruction → Constraints → Output format* prompt, system-instruction personas, and the effect of temperature.

**2. Structured outputs:** used JSON mode and Pydantic schemas to turn free-text LLM responses into validated Python objects for
article summarization, support-ticket triage (classification) and quiz generation.

**3. AI-assisted debugging:** gave Gemini deliberately buggy code, got back a structured bug list and a fix, then **checked the fix
with my own unit tests** before trusting it. Also generated code under constraints and tested it.

**4. Prompt evaluation:** built a `PromptTemplate` class, a labelled test set of 10 support messages, and compared 3 prompt
versions (vague, constrained, role + definitions + few-shot + JSON) on **accuracy, format compliance and latency**. The notebook
auto-generates a Markdown testing report.

**5. AI Productivity Toolkit:** five reusable functions:

| Tool | What it does |
|---|---|
| `summarize(text, style)` | TL;DR, bullet or executive summaries, grounded in the source text |
| `draft_email(points, purpose, ...)` | Professional email with a subject line and call-to-action, returned as JSON |
| `improve_resume(bullets, role)` | Rewrites resume bullets as action + skill + result, without inventing metrics |
| `code_helper(code, task)` | Explain / debug / review code, with structured issues and a fix |
| `research_brief(topic)` | Overview, key concepts, open questions, suggested sources, next steps |

## 💡 Key learnings

- Structure beats clever wording: constraints and an explicit output format make responses consistent.
- Few-shot examples teach format and edge cases better than longer instructions.
- JSON plus schema validation turns an LLM into a dependable software component.
- AI-generated code must be checked with independent tests.
- Prompts should be evaluated like code: versioned templates, a fixed test set and measurable metrics.
